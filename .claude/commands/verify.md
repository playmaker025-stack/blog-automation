# /verify — 자동 교정 루프

코드 수정 후 이 명령어를 실행하면 Claude가 검증 → 실패 분석 → 수정 → 재검증을 모든 검증이 통과될 때까지 반복한다.

## 실행 절차

### 1단계: 검증 실행

```bash
node scripts/verify.mjs
```

### 2단계: 결과 분석

**모든 검증 통과 시** → 완료 선언. 배포 가능 상태.

**실패 시** → 다음 단계로 진행. **실패한 상태로 완료 선언 금지.**

### 3단계: 실패 로그 확인

```bash
# 가장 최근 실패 로그 확인
ls -t data/verify-failures/ | head -1 | xargs -I{} cat data/verify-failures/{}
```

실패 로그에는 다음이 기록된다:
- 어떤 단계에서 실패했는지 (`step`)
- 정확한 오류 메시지 전문 (`error`)
- 종료 코드 (`exitCode`)

### 4단계: 오류별 수정 전략

| 실패 단계 | 수정 방법 |
|-----------|-----------|
| `typecheck` | 오류 메시지의 파일:줄번호 확인 → 타입 오류 수정 |
| `lint` | `npx eslint --fix` 자동 수정 후 잔여 오류 수동 처리 |
| `build` | Next.js 빌드 오류 → 해당 파일 수정 |
| `harness` | 실패한 테스트 케이스 확인 → 구현 로직 수정 (테스트 자체를 수정하지 말 것) |

### 5단계: 수정 후 재검증

수정 완료 후 **1단계부터 다시 실행**. 모든 ✅ 가 나올 때까지 반복.

## 빠른 검증 (빌드/테스트 제외)

```bash
node scripts/verify.mjs --skip-build --skip-test
```

타입 오류 / lint 오류만 빠르게 확인할 때 사용.

## 규칙

- 하나라도 ❌ 가 있으면 완료 선언 금지
- 테스트가 틀렸다고 판단되어도 임의로 테스트를 수정하지 말 것 — 사용자에게 먼저 확인
- 실패 로그는 `data/verify-failures/` 에 자동 저장됨 — 삭제 금지
